# Conversation Log

## 2026-05-17 — A股股票名称搜索与模糊匹配

### 需求

用户反馈 A 股搜索只能用 6 位数字代码，太不方便。需要增加通过股票名称搜索的功能，并支持模糊匹配（如输入"贵州"自动推荐"贵州茅台"）。

### 方案

- 新增股票名称→代码映射表模块
- 前端搜索栏加自动补全下拉框
- 现有行情 API 接口不变——映射层在搜索栏完成转换
- 股票列表在启动时和每隔一段时间自动刷新

### 实现

1. **新增 `stock_list.py`**
   - 从新浪财经 API 拉取全量 ~5516 只 A 股列表
   - 本地缓存到 `stock_list_cache.json`，24 小时自动刷新
   - 模糊匹配搜索，支持：完全匹配、前缀匹配、包含匹配、字符顺序匹配

2. **修改 `stock_server.py`**
   - 新增 `GET /api/stock/search?q=xxx` 端点
   - 启动时后台线程异步刷新股票列表

3. **修改 `static/dashboard.html`**
   - 搜索栏支持输入名称或代码
   - 输入时下拉显示匹配建议（名称 + 代码）
   - 键盘 ↑↓ 导航、Enter 选中、Escape 关闭
   - 兼容原有 6 位数字代码直接查询

### 数据源

- **行情数据**（实时/历史）：腾讯 `qt.gtimg.cn` API（保持不变）
- **股票列表**（名称↔代码映射）：新浪财经 API

### 关键决策

- 东方财富 API 实测不通（服务器空响应），改为新浪财经
- 不引入新的 Python 依赖，只用标准库 + 已有的 `requests`
- 有缓存时优先读缓存（快速启动），后台异步刷新
